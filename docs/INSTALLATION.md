# 安装位置、更新与文件清理

## 安装后程序在哪里？

通过 `python3 install.py`（Windows 为 `py -3 install.py`）安装时，程序与数据分开放置：

| 位置 | 用途 | 是否可删除 |
|---|---|---|
| 下载或克隆的 `opencode-usage/` | 源码和安装脚本 | 安装成功后可删；开发或使用 Git 更新则保留 |
| `~/.local/share/ocusage-app/` | 独立 Python 环境及已安装 OCU | 使用期间保留，删除会导致启动入口失效 |
| `~/.local/bin/ocu`、`ocusage` | macOS / Linux 启动入口 | 使用期间保留 |
| `~/.local/bin/ocu.cmd`、`ocusage.cmd` | Windows 启动入口 | 使用期间保留 |
| 当前工作目录 | 总台账、导入导出文件、报告与备份 | **保留并定期备份，这是个人数据** |
| `~/.config/ocusage/` | 本机身份与工作目录指针 | 不要随意删除，否则可能丢失设备身份或找不到台账 |

`~` 表示当前用户主目录。默认工作目录为 `~/.local/share/ocusage/`，迁移后以启动面板显示的位置为准，例如 OneDrive 下的 `ocusage-mac/`。程序目录 `ocusage-app/` 不是数据工作目录。

### 其他安装方式

- `pip install --user .`：安装到该 Python 的用户包目录，入口通常位于用户脚本目录，不一定存在 `ocusage-app/`。
- 在自行创建的虚拟环境中安装：程序位于那个虚拟环境，运行需要对应入口或激活环境。
- 普通 `pip install .` 安装成功后也可删除源码。
- **开发模式 `pip install -e .` 仍依赖源码，不能删除或随意移动源码目录。**

有多个 Python 环境时，需使用实际运行 OCU 的 Python 检查或卸载包，不能假定系统的 `pip` 管理的是同一份安装。

## 删除源码后怎样更新？

菜单 **设置 → 更新** 可独立下载并更新，不依赖原源码目录；仍需可用的 GitHub 网络和仓库访问权限。也可以重新下载源码，运行安装脚本。

若保留 Git 源码目录，可运行 `python3 install.py --update`；ZIP 解压目录不能使用 Git 拉取，应下载新版 ZIP。

更新程序不清空工作目录。删除报告后可重新生成，但删除总台账可能丢失已从 OpenCode 删除、只保留在 OCU 中的历史。

## 哪些文件适合清理？

- **源码下载包和非开发源码目录**：确认不是可编辑安装后可清理。
- **旧工作目录**：迁移成功后，先确认启动面板指向新目录，并核对记录、快照和备份已完整迁入，再自行删除旧目录。
- **报告文件**：可重新生成；若需历史报告，应先归档。
- **导入收件箱**：成功合并后自动清理，失败文件保留重试；删除文件不会撤销已入账记录，长期备份请另存导出文件。
- **导出快照**：`exports/` 内程序导出仅保留最近成功的一份；需长期保存请复制到外部目录。完整导出默认含台账已有标题/路径，仅用量模式不含，均不能完全替代工作目录备份。
- **自动备份**：新建文件，不覆盖上一份；超过保留份数后清理最旧的一份及其配置副本。默认最近 5 份，可在偏好中改为 1–50。
- **手工迁移或修复备份**：不参与自动轮换，确认不再需要后自行处理。需要长期保留的自动备份可复制到其他安全目录。

不要在 OCU 或其他进程写入时删除数据库及 SQLite 辅助文件。

## 卸载不等于删除数据

安装脚本方式卸载时，可在退出 OCU 后移除其启动入口和 `ocusage-app/` 环境。**这不需要删除工作目录或 `~/.config/ocusage/`**；保留它们便于重装后继续使用。

pip 安装应通过对应环境的 `python -m pip uninstall opencode-usage` 卸载。确认不再需要历史后，才能单独决定是否删除数据；不要将程序卸载与数据清空合并成一步。

## 备份范围

OCU 自动备份主要是 `ledger.db`，旁边保存配置副本；恢复只恢复台账，不覆盖当前设备身份、路径和偏好。它不备份 OpenCode 完整对话、源数据库、全部快照或报告，也不是异地备份。

需要完整备份时，停止写入后备份**当前工作目录**，并另存本机的 `~/.config/ocusage/` 配置；在新机器上不要直接沿用旧机器的设备 ID。详细数据流与恢复限制见[数据说明](DATA_FLOW.md)。
