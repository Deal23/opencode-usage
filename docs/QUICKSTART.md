# 第一次使用与常见问题

## Windows + Mac，三步汇总

1. 两台机器各自安装并运行 `ocu`，分别命名为 Windows、Mac，先刷新一次。
2. 选择数据 → 同步 → 交换目录，指定各自本机看到的同一个 OneDrive 文件夹，例如 Windows 的 `%USERPROFILE%\OneDrive\OCU-sync` 和 Mac 的 `~/OneDrive/OCU-sync`（以实际路径为准）。不要选择 OCU 工作目录。
3. 等云盘传输完成，两台机器各刷新一次。查看设备来源和同步状态；需要标题/项目时，仅对可信设备开启额外共享。

不使用云盘：选 `1` 刷新 → 复制 `exports/` 中生成的 JSON 快照 → 另一台选数据 → 导入快照。完整快照包含已有标题和路径，仅交给可信设备。先预览整批再确认；只有旧版快照另问来源名称。输入 `?` 可选择多份文件，不可用时直接输入或拖入路径。

## 查看报告

主菜单选择 `1` 刷新，再选择 `v` 打开网页看板，或选择 `t` 查看终端报告。终端报告适合 Linux / SSH，使用 `less` 时按 `q` 退出；文件保存在工作目录的 `reports/report.txt`。

- **筛选**：在顶部选择日期、设备、提供商和模型；消息明细的搜索只影响该表。
- **每日趋势**：选择时间范围，使用滚轮缩放、拖动平移或按住 Shift 框选放大；点击日期可查看当日会话。
- **模型分布**：点击模型查看供应商明细。
- **本机会话**：在每日趋势下方重命名会话、打开目录或进入会话，也可批量删除。
- **刷新报告**：点击看板顶部按钮更新数据；如需交互输入，请返回终端。

从主菜单打开的看板支持交互操作，需保持 OCU 运行；直接打开保存的 HTML 为只读模式。

## 设置与价格

看板右上角可检查更新或进入设置，管理设备、数据源、同步和工作目录，也可导入快照、备份或恢复数据。更新程序或迁移工作目录后，重新运行 OCU。

在 **数据 → 模型参考价格** 查看价格与缺价状态，维护方法见[模型价格维护手册](AUTOMATION.md#模型价格维护手册)。

## 会话管理

主菜单选择 **3 会话**，查看当前本机 OpenCode 服务的会话。输入 `o` 进入、`r` 重命名，或选择 `d` 按编号删除、`b` 框选删除。

- 编号删除支持 `2-3,5,7-9`；框选使用方向键移动、空格选择、回车确认。终端不支持框选时可使用编号删除。
- 删除前会列出受影响的子会话，输入 `DELETE` 才执行。删除会移除 OpenCode 对话；此前已采集的 OCU 用量保留，删除前请先刷新采集。
- 会话管理需要支持 API 的 `opencode` 命令；使用当前本机 OpenCode 服务，可能与 OCU 配置的数据源不同。操作后刷新报告更新看板。
- 网页操作需要保持 OCU 运行；直接打开保存的 HTML 时为只读报告。网页刷新无需终端输入，若需要指定数据源等交互操作，请使用主菜单刷新。
- 进入会话时 OCU 退出并释放工作目录锁；退出 OpenCode 后返回终端，需要时重新运行 `ocu`。

## 常见问题

**导出来自哪里？** 来自主台账，包含本机和已经合并的其他设备历史；导出不会先刷新，想要最新数据先选 1。

**反复转发会重复吗？** 不会按文件累加，按消息 ID 合并；设备来源保留。新版快照不再询问来源名称，旧版才补名称。

**为什么标题/项目少了？** 旧快照、仅用量导出或默认自动交换不带标题和路径。重新刷新源设备并导入 `exports/` 的完整快照，即可补齐已有字段，不必删除台账。自动交换仍需主动开启可信模式。看板“信息完整度”显示覆盖情况；用量本身可能完整。

**需要把文件放入 imports 吗？** 不需要，直接选择或输入路径导入。内部 `.state/inbox/` 保存重试副本，失败后数据菜单显示 r 重试；旧 imports 中快照会在正常启动时迁入，空目录移除，未知文件保留。外部源文件不删除。

**为什么有设备未更新？** 检查对方是否运行刷新、云盘是否完成传输，以及源库采集是否成功。无心跳的旧版设备只能根据快照时间判断；不等于数据一定丢失。

**Windows 提示找不到 ocu？** 完全退出并重开终端或 VS Code。仍不可用时用 PowerShell 执行：

```powershell
& "$HOME\.local\bin\ocu.cmd"
```

**更新失败怎么办？** 下一次启动会显示后台安装结果和日志位置；可重新下载源码运行 `py -3 install.py`，不需删除台账。

**如何分享诊断？** 设置 → 高级 → 诊断 → 导出脱敏诊断，只输出允许的状态字段，不包含用户名路径、设备身份或对话。分享前仍请自行检查。
